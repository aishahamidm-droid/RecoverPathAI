# RecoverPath AI v2

A responsible-AI concussion recovery diary for Hack for Humanity Summer 2026.

## Features
- Daily symptom diary
- Random Forest pattern classification
- Recovery timeline
- Daily Recovery Plan
- Pattern Insights
- Doctor Visit Summary
- Deterministic emergency red-flag safety layer
- Explicit responsible-AI guardrails

## Run
```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python app.py
```
Open http://127.0.0.1:5000

This educational prototype is not a medical device or diagnosis tool.
